# Документы системы Прачары

Эта папка содержит единую версию системы для чтения в Word.

## Файлы

- **Система_Прачары.docx** — актуальная книга системы.
- **Карта_системы.md** — краткая карта разделов и связей.
- **build_system_doc.py** — сборка Word из Markdown-страниц сайта.
- **requirements-docs.txt** — зависимость для сборки.

## Источник истины

Главным источником остаются Markdown-файлы в папке ../docs и навигация ../mkdocs.yml. Word-документ создаётся из них автоматически.

Не вносите окончательные изменения только в Word: иначе сайт и документ разойдутся. Если правка сделана в Word, перенесите принятое изменение в соответствующий Markdown-файл и снова соберите документ.

## Повторная сборка

Из корня проекта:

1. Установите зависимость: python -m pip install -r Документы_системы/requirements-docs.txt
2. Запустите: python Документы_системы/build_system_doc.py
3. Проверьте новый файл Документы_системы/Система_Прачары.docx
4. Соберите сайт командой mkdocs build --strict
5. Сохраните и опубликуйте изменения.

Документ использует порядок разделов из mkdocs.yml. Новая страница автоматически попадёт в Word, если она добавлена в навигацию сайта.

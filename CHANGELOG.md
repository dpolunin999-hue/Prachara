# История изменений

## 1.7 — 2026-09-24

- Перенесено компактное недельное расписание в раздел «Встречи».
- Добавлено полное редактирование встречи: тип, дата, состав участников и комментарий.
- Упрощена карточка человека и форма добавления: одно поле полного имени, без фамилии и отметки первого занятия.
- Добавлен автоматический статус «Иногда приходит» для участников с историей более трёх визитов и 1–2 посещениями за последние 30 дней.
- Убран плавающий плюс и лишние поясняющие подписи; быстрые кнопки приведены к единому виду.
- Роль «Администратор страны» переименована в «Секретарь бхукти по прачару».

## 1.6 — 2026-09-24

На экране входа добавлена заметная кнопка «Забыли пароль?» с отправкой письма для восстановления и экраном установки нового пароля. На главной странице постоянное действие переименовано в «Добавить встречу» и дополнено подсказкой о выборе типа и даты. Обновлён кэш PWA, чтобы изменения быстрее появились на установленных телефонах. В `DEPLOY.md` добавлена актуальная памятка владельца о GitHub Pages, Supabase, резервных копиях и восстановлении при сбоях. В публикацию добавлена автоматическая проверка JavaScript.

## 1.5 — 2026-09-21

Улучшена пилотная версия Ananda Prachar: добавлены первый выбор города, типы встреч, заметный статус контакта, копирование заботливого сообщения, открытие указанного контакта, восстановление пароля и дружелюбные ошибки. Удалена несвязанная с встречей кнопка отметки визита. Аналитика повторных приходов теперь считается по фактическим участникам выбранного периода, а регулярность — по трём посещениям за последние 30 дней.
\n\n## 1.4 — 2026-09-20\n\nДобавлено независимое PWA «Ananda Prachar» с авторизацией по электронной почте, общей базой Supabase, учётом людей и встреч, аналитикой, установкой на телефон и безопасными правами по выбранному городу. Приложение публикуется вместе с сайтом на GitHub Pages.\n

## 1.3 — 2026-09-20

Добавлен стартовый обязательный минимум цифровых средств юнита:

- сообщество во ВКонтакте;
- объявление на Avito;
- чат для новичков и практикующих.

В раздел привлечения добавлены прямая ссылка на создание объявления Avito, раскрывающийся шаблон и чек-лист подготовки к публикации.

В систему заботы добавлены назначение чата, правила его ведения, рекомендации для команды с ограниченными ресурсами и шаблон закреплённого сообщения.

Добавлен план развития сайта: публичный запуск, обязательное ядро, библиотека шаблонов, дизайн, проверка в юнитах и постоянное обновление.

Обновлены документы «Три блока Прачары», «Инфраструктура юнита», «Система привлечения» и «Система заботы».


## 1.2 — 2026-09-19

Сайт опубликован на GitHub Pages: сборка из Markdown запускается автоматически при каждом изменении в `docs/`.

База дополнена практическим операционным слоем из внешнего источника «Методичка для представителей». Действующая архитектура сохранена, новые материалы разложены по существующим разделам.

Добавлены страницы:

- `docs/03_Юнит/Профиль_развития_юнита.md` — профиль зрелости по восьми направлениям и четырём стадиям;

- `docs/05_Привлечение/Правила_общения_с_аудиторией.md` — правила общения, границы публикаций, тон.

Дополнен `docs/10_Метрики/Система_показателей.md`: этапы пути человека, постановка целей по ориентирам 1 / 0,7 / 0,5 / 0,3, пример расчёта на 8 недель, цикл гипотез улучшения.

Обновлены `mkdocs.yml` (навигация) и главная страница (быстрый доступ). Положения, требующие утверждения, помечены как «ТРЕБУЕТ РЕШЕНИЯ» согласно `AGENTS.md`.

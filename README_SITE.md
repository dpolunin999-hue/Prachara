# Сайт «Система Прачары»

Это сайт-база знаний, который MkDocs Material собирает из Markdown в `docs/`. Все содержательные изменения вносятся в Markdown; `site/` — только результат сборки.

## Где что находится

- `docs/index.md` — главная страница с маршрутами по ролям.
- `docs/start/` — первые шаги для участников команды.
- `docs/01_Архитектура/` … `docs/13_Разработка_системы/` — исходная база без потери документов.
- `docs/assets/images/` — изображения и инфографики.
- `docs/13_Разработка_системы/Оформление_материалов.md` — примеры схем, карточек, таблиц и выделенных блоков.
- `mkdocs.yml` — навигация, поиск и настройки темы.

## Как посмотреть и обновить

Установите зависимости: `pip install -r requirements.txt`. Запустите `mkdocs serve` и откройте адрес из терминала. Перед публикацией выполните `mkdocs build --strict`.

Подробная инструкция для GitHub и Cloudflare Pages находится в [DEPLOY.md](DEPLOY.md).

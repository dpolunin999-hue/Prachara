# Система первого опыта

## Цель
Создать условия, в которых человек получает хороший первый опыт практики и общения.

## До прихода
Ответить, объяснить формат, дать адрес и время, при необходимости уточнить опыт и запрос, предупредить команду.

## Пространство
Чисто, уютно, понятно куда пройти, есть встречающий человек, новичок не остаётся один.

## Встреча
Познакомиться, запомнить имя, узнать источник, мягко понять запрос, объяснить формат, познакомить с людьми.

## Практика
Использовать понятную ведомую медитацию, философию давать простым языком, при асанах уточнить ограничения, не перегружать.

## Завершение
Узнать впечатления, ответить на вопросы, обменяться контактом, пригласить на следующий шаг.

## Критерии успеха
### Минимум
Человек познакомился, попробовал практику, контакт сохранён, запрос понятен, он знает следующий шаг.
### Хорошо
Хочет прийти ещё раз.
### Отлично
Хочет учиться самостоятельно и углубляться.

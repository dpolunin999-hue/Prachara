# Цикл развития системы Прачары

**Разработка → Внедрение → Практика в юнитах → Обратная связь → Анализ → Улучшение → Обновлённый стандарт**

Новая идея может быть разработана Центром, прийти из практики юнита, быть заимствована из уже работающего опыта или появиться как ответ на проблему.

## Рабочая логика
1. понять идею;
2. оценить применимость;
3. встроить в систему;
4. применить в юнитах;
5. получить обратную связь;
6. доработать.

## Продукт Центра
Каждое направление стремится создавать готовые продукты: чек-листы, инструкции, программы, шаблоны, скрипты, курсы, базы, регламенты, наборы материалов.

## Критерий
Прачарщик должен быстро понять: **что делать, как делать и какой результат должен быть.**

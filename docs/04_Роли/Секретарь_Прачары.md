# Роль: Секретарь Прачары юнита

## Цель
Организовать целостную работу Прачары в юните.

## Зона ответственности
Видеть систему, определять приоритеты, видеть незакрытые направления, распределять функции, собирать команду, организовывать выполнение, использовать инструменты Центра, контролировать результат, передавать обратную связь.

## Минимальный результат
- понятны активные и незакрытые направления;
- назначены ответственные там, где это возможно;
- есть конкретные задачи;
- есть регулярные программы;
- ведётся работа с людьми;
- есть обратная связь и показатели.

Если команда маленькая, секретарь может лично выполнять часть функций, но продолжает видеть систему целиком.

# Система обучения прачарщиков

## Цель
Сделать так, чтобы человеку не нужно было самостоятельно придумывать, как выполнять свою функцию.

## Уровни
### 1. Вводное
Что такое Прачара, цель, три блока, путь человека, структура департамента.
### 2. По ролям
Секретарь, контент-мейкер, заботник, ведущие программ и другие роли.
### 3. По задачам
Ответ на обращение, приглашение, встреча новичка, публикация, объявление, программа, учёт.
### 4. Практика
Применение инструмента, обратная связь, разбор ошибок, улучшение.

## Форматы
Короткие инструкции, чек-листы, видео, встречи, курсы, кейсы, наставничество.

## Результат
**Что делать → как делать → каким инструментом → какой результат получить.**

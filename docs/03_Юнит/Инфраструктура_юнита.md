# Инфраструктура юнита

## Цифровая инфраструктура
- хотя бы одна активная социальная площадка;
- VK-сообщество;
- Telegram-канал;
- Telegram-чат;
- чат для новичков или практикующих;
- личные страницы активных прачарщиков;
- Avito-объявление;
- карты и локальные сервисы;
- база людей;
- рабочий чат команды;
- хранилище контента.

### Обязательный минимум

- сообщество юнита во ВКонтакте;
- объявление на Avito;
- чат для новичков и практикующих в доступной людям социальной сети или мессенджере.

Даже если команда пока не может вести чат активно, он должен существовать как понятный и регулярно проверяемый канал связи.

## Материальная инфраструктура
- помещение;
- коврики;
- подушки;
- литература;
- визитки;
- афиши;
- музыкальные инструменты;
- оборудование для программ;
- фото/видео оборудование при наличии;
- чай и всё для гостеприимства.

## Минимальный принцип
У юнита должны быть понятный способ найти его, связаться, место для практики, базовые материалы и канал регулярного контакта.

## Статус
Этот цифровой минимум принят как стартовый. Остальной обязательный минимум для разных типов юнитов ещё требует утверждения.

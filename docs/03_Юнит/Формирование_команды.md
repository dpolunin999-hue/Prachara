# Формирование команды юнита

## Главный принцип
**Функции фиксированы, люди гибки.**

В маленьком юните один человек может совмещать несколько функций.

## Алгоритм
**Потребность → Человек → Предложение → Вдохновение → Согласие → Объяснение функции → Инструмент / обучение → Старт → Поддержка → Ответственность за результат**

## Если человека нет
- функция остаётся видимой;
- никто не назначается насильно;
- временно её берёт тот, кто способен;
- секретарь продолжает искать возможность закрыть направление.

## Формат роли
1. цель;
2. зона ответственности;
3. задачи;
4. минимальный результат;
5. взаимодействие;
6. инструменты;
7. отчётность.

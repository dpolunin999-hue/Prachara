# Источники

Раздел для внешних материалов, используемых при развитии системы Прачары.

## Сюда добавлять
Выгрузки с сайтов, официальные документы, архивы, методические материалы, тексты, ссылки и конспекты, материалы учителей, примеры из других регионов.

## Правило
Внешний источник не становится автоматически частью принятой системы.

Сначала: сохранить → понять → сравнить → выделить полезное → решить, что интегрировать → зафиксировать изменение.

## Для будущей выгрузки сайта
`12_Источники/Сайт_название/`
- `raw/` — исходные материалы;
- `processed/` — очищенные материалы;
- `summary.md` — краткое содержание;
- `integration_notes.md` — что стоит встроить.

# Организационная структура Прачары

## 1. Центр Департамента Прачары

**Назначение:** создавать, систематизировать и развивать единую систему Прачары.

### Основные функции
- разработка методик;
- разработка инструментов;
- разработка программ;
- обучение прачарщиков;
- развитие системы привлечения;
- развитие системы первого опыта;
- развитие системы заботы;
- сбор лучших практик;
- внедрение разработок в юниты;
- сбор обратной связи;
- постоянное улучшение системы.

## 2. Секретари Прачары в юнитах

**Назначение:** организовывать и координировать работу Прачары в своём юните.

### Основные задачи
- понимать все направления работы юнита;
- видеть, какие направления закрыты, а какие нет;
- распределять функции;
- находить и вдохновлять людей;
- организовывать выполнение задач;
- использовать инструменты Центра;
- следить за результатом;
- передавать обратную связь в Центр.

## 3. Команды юнитов

**Назначение:** реализовывать систему Прачары на практике.

### Возможные функции
- контент;
- привлечение;
- работа с обращениями;
- забота;
- проведение программ;
- обучение медитации;
- киртан;
- карма-йога;
- учёт людей;
- другие функции юнита.

## Принцип распределения

**Функции фиксированы, люди гибки.**

Один человек может совмещать несколько функций. Если на функцию пока нет человека, она остаётся видимой как незакрытая.

## Схема

**ЦЕНТР → СЕКРЕТАРИ → КОМАНДЫ → ЛЮДИ**

Обратная связь:

**ОПЫТ И ОБРАТНАЯ СВЯЗЬ → СЕКРЕТАРИ → ЦЕНТР**

> Центр создаёт систему. Юниты реализуют её. Практика помогает системе становиться лучше.

# Путь человека в системе Прачары

## Общая цепочка

**Узнал → Заинтересовался → Пришёл → Хочет научиться → Начал практиковать → Хочет углубляться → Инициация → Сообщество / Садхана**

## Укрупнённая карта

### 1. Привлечение
Узнал → заинтересовался.

### 2. Первый опыт
Пришёл → попробовал → получил первое впечатление.

### 3. Начало практики
Хочет научиться → учится → начинает практиковать регулярно.

### 4. Углубление и сообщество
Углубляется → получает личный урок / инициацию → включается в садхану, сообщество и служение.

## Принцип

Человека не «проталкивают» по этапам. Задача Прачары — понять его запрос, дать полезный опыт, показать следующий естественный шаг и создать условия для движения.

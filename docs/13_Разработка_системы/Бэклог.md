# Бэклог развития системы

## Статусы
Идея → Нужно разработать → В разработке → Готово → Внедрено → Получена обратная связь → Обновлено

## Ближайшие направления

### Карта задач юнита
Уточнить полный список, обязательный минимум, убрать лишнее и добавить недостающее.

### Роли
Вывести роли из карты задач, описать по единому шаблону, определить минимальный результат.

### Программы
Оформить каждую программу отдельной карточкой, определить частоту, сценарий и следующий шаг.

### Забота
Сделать готовые скрипты, типовые сценарии, этапы до инициации.

### Инфраструктура
Определить обязательный минимум и рекомендуемое.

### Метрики
Утвердить минимальный набор, создать таблицу учёта, определить отчётность.

### Обучение
Создать вводный курс, инструкции по ролям и короткие практические уроки.

### Контент
Создать систему контента, шаблоны, стандарты упаковки, инструкцию для контент-мейкера.

### Источники
Выгрузить структуру Прачары с внешнего сайта, сохранить в `12_Источники`, сравнить и интегрировать полезное.

# Рабочие ссылки моего города

**Сохраните рабочие инструменты один раз, чтобы открывать их из нужного шага.**

В блоке «Рабочие ссылки моего города» укажите город и ссылки на календарь, форму записи, ответы регистрации, учёт обращений и рабочий чат. Приложение заботы уже доступно.

- Ссылки сохраняются в этом браузере. На другом устройстве добавьте их снова.
- Кнопка «Скопировать ссылки для команды» готовит сообщение; закрепите его в рабочем чате, чтобы коллеги тоже могли сохранить ссылки.
- Доступ к закрытым документам выдаёт их владелец. Сохранение ссылки не открывает документ другим людям.
- Меняете форму или календарь — обновите ссылку и сообщение для команды.

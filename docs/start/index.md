# Начать работу

Выберите свою задачу. Маршруты ниже помогают быстро войти в работу и ведут к основным документам базы.

<div class="grid cards" markdown>

- **[Я секретарь Прачары](secretary.md)**  
  Собрать картину работы юнита и организовать команду.
- **[Я заботник](caretaker.md)**  
  Встретить человека и помочь ему сделать следующий шаг.
- **[Я отвечаю за контент](content.md)**  
  Показать практику, события и понятный способ прийти.
- **[Я провожу программы](programs.md)**  
  Подготовить встречу и продолжение после неё.
- **[Я только начинаю](beginner.md)**  
  Понять устройство системы и найти посильную задачу.
- **[Мне нужен материал](materials.md)**  
  Найти документ по роли, этапу или рабочему вопросу.

</div>

Если ваша задача охватывает несколько направлений, начните с [карты задач юнита](../03_Юнит/Карта_задач_юнита.md).

## Сделать сначала { #direction-minimum }

**Первый результат:** Связать рекламу, программы и заботу вокруг ближайшей встречи.

1. Назначьте ответственного за каждое направление. Один человек может совмещать роли. [Инструкция: Распределить ответственность](../secretary.md#work-areas)
2. Согласуйте ближайшую программу: кто проводит, кого приглашаем и кто сопровождает. [Инструкция: Согласовать встречу](../programs.md#program-preparation)
3. Запишите по одной ближайшей задаче на направление: действие, ответственный, срок, ожидаемый результат. [Инструкция: Зафиксировать задачи](../secretary.md#target-actions)
4. Договоритесь о следующем разборе: что выполнено, сколько людей обратилось и пришло, какой следующий шаг. [Инструкция: Провести разбор](../secretary.md#team-call)

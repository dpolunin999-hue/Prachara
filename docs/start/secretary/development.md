# Секретарь: развитие блока

<div class="direction-guide" data-direction-group="secretary" markdown="1">

[← Секретарь](../secretary.md){ .care-return }

В начале месяца согласуйте по одному усилению каждого блока: рекламная гипотеза, дополнительная программа, улучшение заботы. В конце месяца вместе разберите результат и выберите следующий шаг. Обучайте команду и усиливайте слабое направление. Подключайте новые инструменты и форматы по готовности людей, фиксируйте удачные решения и передавайте опыт другим юнитам.

Это рабочий ориентир этапов; выбирайте темп по возможностям юнита. Не нужно включать все инструменты сразу.

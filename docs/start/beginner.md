# Я только начинаю заниматься Прачарой

Вам не нужно сразу знать всю базу. Сначала поймите общий путь человека, затем выберите одну посильную функцию рядом с опытной командой.

## С чего начать

1. Прочитайте [обзор системы](../11_База_знаний/Обзор_системы.md).
2. Посмотрите [три блока Прачары](../01_Архитектура/Три_блока_Прачары.md) и [путь человека](../01_Архитектура/Путь_человека.md).
3. Обсудите с секретарём юнита одну конкретную задачу из [карты задач](../03_Юнит/Карта_задач_юнита.md).

## Какие документы прочитать затем

- [Формирование команды](../03_Юнит/Формирование_команды.md) — как можно включаться постепенно.
- [Система обучения](../09_Обучение_прачарщиков/Система_обучения.md) — обучение по роли и задаче.
- [Роли](../04_Роли/Секретарь_Прачары.md) — ориентир по распределению ответственности.

## Основные задачи

- Понять цель выбранной функции и договориться о первом результате.
- Выполнить небольшую задачу вместе с командой.
- Рассказать, что получилось и что было трудно.

## Куда дальше

Когда задача станет понятнее, откройте маршрут [заботника](caretaker.md), [контента](content.md) или [программ](programs.md) по вашему направлению.

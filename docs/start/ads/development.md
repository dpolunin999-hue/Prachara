# Реклама: развитие блока

<div class="direction-guide" data-direction-group="ads" markdown="1">

[← Реклама](../content.md){ .care-return }

Каждый месяц проверяйте одну новую рекламную гипотезу: инструмент, площадку или способ приглашения. Запишите ожидаемый результат, проведите тест и сравните обращения и приходы. Поддерживайте работающий минимум; по результату оставьте инструмент, доработайте или остановите. [Открыть цикл проверки](../content.md#ad-experiment).

Это рабочий ориентир этапов; выбирайте темп по возможностям юнита. Не нужно включать все инструменты сразу.

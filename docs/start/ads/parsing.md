# Парсинг для Сита

<div class="ads-guide" markdown="1">

[← К методам](methods.md){ .care-return }

**Назначение парсинга — находить потенциально заинтересованных людей по публичной активности в городских йога-сообществах ВКонтакте.** Планируется помощь ИИ в подборе. На выходе предполагаются ссылки на профили для дальнейшего ручного знакомства.

Систему разрабатывает **сестра Мадувати**. Готового инструмента и утверждённой инструкции в методичке пока нет; после разработки добавим запуск и порядок работы.

Лайк или комментарий показывает возможный интерес к теме, а запрос выясняется в общении. Пока можно пользоваться [«Ситом» вручную](sito.md).

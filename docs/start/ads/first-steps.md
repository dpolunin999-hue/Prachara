## Сделать сначала { #direction-minimum }

**Первый результат:** Опубликовать понятное приглашение и наладить ответы на обращения.

1. Уточните ближайшую встречу: дата, место, формат, контакт и условия участия. [Инструкция: Подготовить встречу](../programs/first-steps.md#program-preparation)
2. Оформите группу ВКонтакте: город, описание, расписание и способ написать. [Инструкция: Упаковать соцсети](../content.md#social-packaging)
3. Создайте объявление Avito из шаблона. Проверьте дату и контакт. [Инструкция: Открыть шаблон Avito](../content.md#avito-tool)
4. Назначьте того, кто отвечает на сообщения и передаёт запрос заботнику. [Инструкция: Передать обращение](../care/journey.md#care-step-1)

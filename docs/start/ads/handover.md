# Передать обращение заботнику

<div class="ads-guide" markdown="1">

[← В рекламу](../content.md){ .care-return }

**Обычно на запрос отвечает заботник.** По ситуации команда может назначить другого ответственного; порядок должен быть понятен до публикации.

1. Уточните, кто проверяет сообщения ВКонтакте, Telegram, Avito и других площадок.
2. Передайте заботнику контакт, источник, дату и уже известный запрос.
3. Убедитесь, что ответственный принял обращение и человек получил ответ.
4. Сверяйте регистрацию и первый приход, чтобы понимать результат рекламы.

[Первый ответ заботника](../care/journey.md#care-step-1).

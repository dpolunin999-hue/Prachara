**Здесь будет авторский промпт для монтажа коротких видео и ведения видеоконтента.** Он ещё не передан в методичку. По описанию автора, работа рассчитана на платную версию ChatGPT; точную инструкцию запуска добавим вместе с промптом.

Уже можно публиковать небольшие реальные видео с понятной подписью. Обрежьте лишнее в начале и конце; при необходимости соедините несколько кадров. Выбирайте посильный объём.

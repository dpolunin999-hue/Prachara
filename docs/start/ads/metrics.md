# Учёт и цели рекламы

<div class="ads-guide" markdown="1">

[← В рекламу](../content.md){ .care-return }

**Главный результат рекламы — новые обращения.** Регистрации и первые приходы показывают, как человек движется дальше.

| Показатель | Что считать | Где проверить |
| --- | --- | --- |
| Обращения | Новых людей, написавших или позвонивших по приглашению; повторные сообщения одного человека не новые обращения | Рабочий учёт обращений |
| Регистрации | Людей, записавшихся на программу | Общая форма организатора |
| Первые приходы | Людей, впервые фактически посетивших программу | Отмеченные посещения в приложении |

Для каждого обращения сохраните дату, источник, контакт и назначенного заботника. Команда сверяет записи; имя метода, например «Сито», можно уточнять в рабочем журнале.

<details markdown="1" class="ads-action">
<summary>Предложение по количественным целям</summary>

**Сейчас общие нормы не утверждены.** Предлагаю первые четыре недели вести полный учёт без единого плана обращений для всех городов.

1. Зафиксируйте обращения, регистрации и первые приходы по источникам.
2. Посмотрите результат своего города и сколько времени реально тратит команда.
3. Выберите ориентир на следующий период: поддержать работающий поток и проверить дополнительный метод.
4. Согласуйте конкретное число обращений после появления своей исходной статистики.

Первый ориентир процесса — у каждого обращения есть источник, ответственный и понятное продолжение. Численные планы опираются на данные и возможности своего города.

</details>
<details markdown="1" class="ads-action">
<summary>Как сравнивать методы</summary>

Смотрите, сколько людей обратилось, зарегистрировалось и пришло по каждому источнику. Для оценки переходов сравнивайте одних и тех же людей; приходы в этом месяце могут относиться к обращениям прошлого.

Регистрации и обращения пока нужно сверять с формой и рабочим учётом. Счётчик новых карточек в приложении сам по себе не равен числу рекламных обращений.

</details>

# Обязанности ответственного за рекламу

<div class="ads-guide" markdown="1">

[← В рекламу](../content.md){ .care-return }

**Ведите свой блок в темпе, который команда может поддерживать.**

1. Проверяйте и обновляйте [страницы и объявления](landing.md).
2. Ищите площадки, договаривайтесь с группами и партнёрами. [Методы](methods.md).
3. Поддерживайте контент вместе с тем, кто помогает с фото и видео. [SMM](content.md).
4. Выбирайте и проверяйте новую гипотезу по ресурсам команды. [Гипотезы](hypotheses.md).
5. Передавайте обращения заботнику и сверяйте результат. [Передача](handover.md).
6. Считайте обращения, регистрации и первые приходы. [Учёт](metrics.md).

Организатор программы может сам публиковать анонс или передать его в рабочем чате. Рекламщик помогает с площадками и распространением. [AMA V8 для анонса](../programs/announcement.md).

Бюджет согласует **секретарь по прачару в городе**. Продолжать инструмент или остановить — команда решает по результатам на совместном разборе.

</div>

# Личный бренд

<div class="ads-guide" markdown="1">

[← К контенту](content.md){ .care-return }

**Личный бренд — отдельная методика, которую готовит команда.** Готовый материал будет интегрирован сюда после получения.

Роль инструмента — помогать людям знакомиться с реальным ведущим или организатором и его опытом. Пока начинайте с доступных [методов](methods.md) и [контента сообщества](content.md).

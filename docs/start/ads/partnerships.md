# Партнёрства

<div class="ads-guide" markdown="1">

[← К методам](methods.md){ .care-return }

**Договоритесь о понятном совместном действии.** Студия, блогер или дружественный проект могут помочь познакомить людей с программой.

1. Выберите партнёра с подходящей аудиторией.
2. Предложите конкретный формат: совместный анонс, встречу, размещение или время в студии.
3. Согласуйте пользу для обеих сторон, условия, ответственных и дату.
4. Проведите пробу и отметьте источник обращений.
5. Разберите результат с командой и партнёром.

# С чего начать заботу

<div class="care-guide" markdown="1">

[← В заботу](../caretaker.md){ .care-return }

**Первый результат:** контакт сохранён, человек знает ближайшую встречу, заботник помнит следующий шаг.

1. Назначьте заботника — кто отвечает человеку и сохраняет договорённости.
2. Подготовьте [приложение](application.md): город, контакты, встречи и задачи заботы.
3. Создайте [чат](chat.md): расписание, контакт и короткие правила без спама.
4. Получили контакт из рекламы — переходите к [первому ответу](journey.md#care-step-1).

<details markdown="1" class="care-action">
<summary>Минимум готов к работе?</summary>

- [ ] Есть ответственный и доступ к приложению.
- [ ] Чат создан; расписание и способ связи понятны.
- [ ] У каждого контакта есть ближайшее действие и дата связи.
- [ ] [Готовые материалы](resources.md) доступны для быстрого копирования.

</details>

</div>

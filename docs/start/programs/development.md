# Программы: развитие блока

<div class="direction-guide" data-direction-group="programs" markdown="1">

[← Программы](../programs.md){ .care-return }

Каждый месяц добавляйте одну программу помимо еженедельной коллективной медитации: например, кино с обсуждением, поход или тематическую встречу. Выбирайте формат по интересам людей и возможностям команды. [Открыть план программы месяца](../programs.md#program-month). Детальные стандарты наполним по ответам команды.

Это рабочий ориентир этапов; выбирайте темп по возможностям юнита. Не нужно включать все инструменты сразу.

# Обязанности ответственного за программы

<div class="program-guide" markdown="1">

[← В программы](../programs.md){ .care-return }

**Ответственный за программы поддерживает регулярные встречи и планирует дополнительные.** Частоту и количество команда выбирает по возможностям и интересам своего города.

1. **Организовать еженедельные программы.** Согласуйте расписание, ведущих и задачи команды. [Основные программы](formats.md#basic).
2. **Составить план дополнительных встреч.** Определите количество на выбранный период. Например, одна дополнительная встреча в месяц — ориентир, который можно изменить. [Календарь и досуг](routine.md).
3. **Подготовить анонсы и посты.** Передайте людям понятное приглашение за 5–3 дня. [AMA Ready Prompt V8 и инструкция](announcement.md).
4. **Поддерживать качество.** Собирайте пожелания через заботника и выбирайте улучшение. [Качество программ](quality.md).
5. **Проверить учёт участников.** Все реально пришедшие должны быть внесены в приложение заботы; делегированную работу проверяет организатор. [Завершение встречи](first-steps.md#attendance-complete).

Назначайте ведущих и делегируйте подготовку. На регулярном разборе проверяйте, что план выполнен и есть дополнительные встречи помимо обычного расписания.

</div>

## Сделать сначала { #direction-minimum }

**Первый результат:** Подготовить и провести одну понятную, полезную встречу с продолжением.

1. Выберите один формат и сформулируйте пользу для новичка. [Инструкция: Выбрать формат](../programs.md#program-types)
2. Определите ведущего, место, дату, длительность и условия участия. [Инструкция: Подготовить программу](../programs.md#program-preparation)
3. Запишите сценарий: встреча гостей → объяснение → практика → вопросы и общение → следующий шаг. Назначьте ответственных. [Инструкция: Организовать встречу](../programs.md#care-during-program)
4. Проведите встречу, соберите впечатления и передайте договорённости заботнику. [Инструкция: Связь после встречи](../care/journey.md#care-step-4)

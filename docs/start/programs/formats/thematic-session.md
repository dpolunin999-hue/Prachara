## Сценарий встречи

1. **Объяснить тему.** Назовите, что участники смогут попробовать.
2. **Провести занятие.** Ведущий даёт согласованное объяснение и практическую часть.
3. **Обсудить опыт.** Дайте возможность поделиться, спросить и пообщаться.
4. **Завершить.** Предложите подходящее продолжение и отметьте участников.

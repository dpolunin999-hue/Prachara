# Общая форма регистрации

<div class="program-guide" markdown="1">

[← К подготовке встречи](first-steps.md){ .care-return }

**Одна форма для регистрации на программу, общие ответы для команды юнита.** Организатор и заботник видят один список.

<details markdown="1" class="program-action">
<summary>Создать форму</summary>

1. Укажите название встречи, дату, место, условия участия и контакт организатора.
2. Оставьте необходимые поля: имя, контакт для связи и выбранная программа или дата. Дополнительный вопрос — по необходимости.
3. Проверьте с телефона, что запись отправляется и ответы появляются в списке.

</details>
<details markdown="1" class="program-action">
<summary>Открыть доступ команде</summary>

1. Сохраните ссылку на форму для участников и ссылку на ответы для команды.
2. Дайте организатору, заботнику и остальным участникам команды юнита доступ к ответам.
3. Закрепите обе ссылки в общем рабочем месте команды. Ссылку для записи добавьте в анонс.
4. Проверьте доступ под учётной записью заботника.

</details>
<details markdown="1" class="program-action">
<summary>Использовать до и после встречи</summary>

- **До:** организатор смотрит число записавшихся; заботник уточняет участие и помогает прийти.
- **После:** сравните записи с реальными посещениями, добавьте пришедших без регистрации и отметьте всех в приложении.

Запись в форме показывает намерение прийти; посещение в приложении фиксируется после фактического участия.

</details>

</div>
